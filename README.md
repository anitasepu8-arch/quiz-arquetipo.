# Quiz · Tu Arquetipo de Marca (Quantum Branding)

- `index.html`: el quiz completo (una sola página).
- `api/lead.js`: guarda cada lead en MailerLite.

Variables de entorno en Vercel:
- `MAILERLITE_API_KEY` (obligatoria)
- `ML_GROUP_INICIADO`, `ML_GROUP_COMPLETADO` (opcionales: ids de grupos de MailerLite)
